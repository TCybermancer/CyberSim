Changing network/LLM settings requires an admin account.

Network & content generation

Controls whether the server can call out to an LLM for realistic scenario content (like a role-appropriate email body) at run-launch time. Agents themselves never make this call — only this server does, and only when set to "connected". Runs launched with an explicit seed (replays) always use the static template library regardless of this setting, to keep exact reproducibility.

Change your password

Applies to whichever account you're logged in as. A fresh install's built-in admin account starts with the password admin unless CYBERSIM_ADMIN_PASSWORD was set before first startup — change it here as your first step.

Remote install credentials

Configured once here, then reused for every remote install from Install agent → Remote Install — that tab only asks for a target's IP and OS. The server logs into the target with these credentials and has it pull its own install bundle from here, the same way a manual download would.

Server address

Leave blank and the target is told to use whatever address your own browser reached this dashboard on — only correct if that happens to also be reachable from the target. Set this explicitly (this server's OOB-network address) if remote installs fail to download on the target even though the SSH/WinRM connection itself succeeds.
