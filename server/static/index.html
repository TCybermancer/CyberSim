Getting started

  1. Install agents on the hosts you want to simulate activity on — download the Windows installer, pre-linked to this server.
  2. Build a scenario (or use one already on the server) — a persona's schedule of actions, some optionally flagged as red-team activity your detection tooling should catch.
  3. Launch a run below, against one or more registered hosts.
  4. Watch it happen in the live topology and the schedule/ledger below — that's your ground truth for scoring whatever detection tool you're validating.
