Saving a scenario writes a file on the server, so only admin accounts can do this. Ask an admin to build it for you, or to create you an admin account.

Build a scenario

A scenario is a persona's schedule of actions. Each step fires after a random delay, can optionally run for a random duration, and can be flagged as red-team activity your detection tooling is expected to catch. Saving here writes a YAML file into the server's scenario library — the same place hand-authored ones live, and it'll show up in the dashboard's launch form immediately.
