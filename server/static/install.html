Install the Windows agent

Downloads a Windows installer pre-linked to this server — its setup wizard opens with the server address, host ID, and persona already filled in below. You can still change anything before finishing the install.

After downloading

  1. Unzip cybersim-agent-installer.zip and run cybersim-agent-setup.exe.
  2. The wizard's "Orchestrator Connection" page opens pre-filled — confirm or edit the values, then finish.
  3. The agent registers itself and starts automatically the next time this Windows user logs in (it simulates one logged-in user's activity, so it runs at logon, not as a background service — see docs/README.md). Launch it immediately from the installer's final page if you don't want to wait.

Prefer a hands-off setup? The zip also works unattended: cybersim-agent-setup.exe /VERYSILENT uses the same pre-filled values with no prompts.

Server-side install

This page only distributes the Windows agent. To install the orchestrator itself on a new Linux host:

docker compose up -d          # server/docker-compose.yml
# -- or, no Docker --
sudo ./install.sh              # server/install.sh, installs as a systemd service
