Admin access required

Installing an agent mints a live credential for it, so only admin accounts can do this. Ask an admin to run this for you, or to create you an admin account.

Install the Windows agent

Downloads a Windows installer pre-linked to this server — its setup wizard opens with the server address, host ID, and persona already filled in below. You can still change anything before finishing the install.

After downloading

  1. Unzip cybersim-agent-installer.zip and run cybersim-agent-setup.exe.
  2. The wizard's "Orchestrator Connection" page opens pre-filled — confirm or edit the values, then finish.
  3. The agent registers itself and starts automatically the next time this Windows user logs in (it simulates one logged-in user's activity, so it runs at logon, not as a background service — see docs/README.md). Launch it immediately from the installer's final page if you don't want to wait.

Prefer a hands-off setup? The zip also works unattended: cybersim-agent-setup.exe /VERYSILENT uses the same pre-filled values with no prompts.

Install the Linux agent

Downloads a tarball pre-linked to this server — its install script prompts with the server address, host ID, and persona already filled in as defaults. You can still change anything before it finishes.

After downloading

  1. tar xzf cybersim-agent-installer-linux.tar.gz && ./install.sh — no root required, installs under ~/.local/share/cybersim-agent.
  2. Confirm or edit the prompted values (server URL, host ID, persona, token), then it finishes.
  3. Registers as a systemd --user unit and starts it right away — it also starts automatically at this user's next login (same "looks like a real logged-in user, not a background service" intent as the Windows agent — see docs/README.md). Check on it with systemctl --user status cybersim-agent.
  4. Headless host with no interactive login session? Separately run loginctl enable-linger "$USER" so the unit starts even without one.

Prefer a hands-off setup? ./install.sh --silent uses the same pre-filled values with no prompts. ./install.sh --uninstall reverses everything.

Remote install

Installs the agent on a host over the network, without logging into it yourself. Needs credentials configured once under Settings → Remote Install — this server logs into the target with those and has it pull its own install bundle from here, the same way a manual download would. 


      

    


    

      
Server-side install

      
This page only distributes the agent. To install the orchestrator itself on a new Linux host:

      
docker compose up -d          # server/docker-compose.yml
# -- or, no Docker --
sudo ./install.sh              # server/install.sh, installs as a systemd service
